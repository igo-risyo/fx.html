# FX自動売買シミュレーター（USD/JPY）

ブラウザで動く USD/JPY の自動売買シミュレーター。元金10万円・レバレッジ25倍（日本のFX標準）で、実勢レートを基準にしたリアルな値動きを再現します。

## デモ

`https://<あなたのGitHubユーザー名>.github.io/<リポジトリ名>/`

GitHub Pages を有効化すると上記URLでブラウザから直接プレイできます。

## 主な機能

- **元金10万円** からスタート、レバレッジ **25倍** 固定
- **実勢レート自動連動**: GitHub Actions が30分ごとに USD/JPY の最新レートを取得して埋め込みます
- **自動売買プリセット 4種**:
  - バランス型（10pips利確 / 10pips損切り）— おすすめ
  - 安全型（5pips / 5pips・小ロット）
  - 積極型（30pips / 15pips）
  - スキャルピング（3pips / 3pips）
- **証拠金維持率の計算**: マージンコール100% / 強制ロスカット50%
- **手動売買**: 買い・売りを任意のタイミングで実行可
- **シミュレーション状態の永続化**: localStorage に保存され、リロード後も継続
- **チャート・トレード履歴・統計**: Chart.js による可視化

## 使い方

1. リポジトリをクローン、または GitHub Pages 経由で開く
2. 画面上部「⭐ おすすめ（バランス型）」プリセットが選択された状態で「▶ 開始」を押す
3. 自動売買が始まり、利確・損切りが自動実行される
4. 任意のタイミングで「⏸ 停止」「⟲ リセット」、または「手動：買い／売り」も可能

## 注意事項

- 本シミュレーターは **教育・検証目的** のものです。実際の取引・投資判断には使用しないでください
- tick単位の値動きは実勢レートを中心とした **数学的な再現** であり、本物の市場tick配信ではありません
- レート更新の最小粒度は GitHub Actions の cron 仕様により **約30分** です（無料枠の制約）
- 為替市場は **平日のみ稼働**。土日・祝日のレートは更新されません

## 自動レート更新の仕組み

`.github/workflows/update-rate.yml` が以下を行います:

1. 平日30分ごとに無料の為替APIから最新の USD/JPY レートを取得
2. `index.html` 内の `window.FX_AUTO` オブジェクトを書き換え
3. 変更をコミット & プッシュ → GitHub Pages が自動再デプロイ

外部依存:
- [frankfurter.app](https://www.frankfurter.app/) — APIキー不要・無料・CORS対応の為替データAPI
